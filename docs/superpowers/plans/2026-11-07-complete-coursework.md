# Завершение курсовой

**Цель:** автономный выполненный solution.ipynb с EDA, предобработкой, обучением и независимой оценкой классификатора кредитного риска.
**Основание:** docs/specifications/assignment.txt; пользователь поручил закончить самостоятельно и оставить изменения незакоммиченными.
**Технологии:** существующие Pandas / scikit-learn / Matplotlib; семь этапов, соседние _code/ с встраиванием при сборке.

## Ограничения и решения
- Сохранить исходные ячейки EDA, классификацию признаков, разбиение 70/15/15 и эталоны.
- Оставшиеся описательные гипотезы проверить только на train; не выдавать групповые наблюдения за доказательство причинности.
- Включить все 11 признаков. loan_grade/loan_int_rate допустимы только для уже оценённой кредитором заявки согласно постановке.
- Оценивать параметры импутации/масштабирования/кодирования только на train внутри Pipeline.
- Сравнить Dummy, логистическую регрессию, случайный лес и гистограммный бустинг на validation по Average Precision. Ограниченная заранее заданная сетка.
- Выбрать порог по максимуму F2 на validation: учебное предпочтение полноты, не экономическая оптимизация.
- Сохранить train-fitted победителя без переобучения на train+validation, чтобы не менять шкалу выбранного порога.
- Test использовать только после фиксации модели и порога. Показать AP, ROC-AUC, precision/recall/F1/F2, accuracy/balanced accuracy, Brier, confusion matrix, ROC/PR и калибровку.
- Эксплуатация: локальный пакетный прогноз с проверкой схемы, мониторинг и ограничения; не публиковать сервис.
- Новые результаты не коммитить. Работать в текущей папке по прямому поручению пользователя.

## Проверка рисков
- Отсутствие утечки: идентификаторы разбиений не пересекаются; импутация учится на train; test не попадает в подбор.
- Неизвестные/пропущенные категории и неверная схема: определённое поведение и тесты.
- Воспроизводимость: seeds и одно вычислительное ядро для моделей.
- Старые выводы сохраняются как история этапов; последняя таблица заменяет устаревшие решения, а не дублирует их.
- До разбиения уже выполнен общий EDA: признать ограничение независимости, не объявлять test внешней проверкой.
